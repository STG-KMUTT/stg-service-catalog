# คลังบริการ สำนักงานยุทธศาสตร์ (STG Service Catalog)

หน้าเว็บหน้าเดียว รวมภารกิจ/บริการของสำนักงานยุทธศาสตร์ มจธ. **29 รายการ**
พร้อมช่วงเวลาดำเนินการรายเดือน สถานะตามปฏิทิน และทีมที่รับผิดชอบ

## มุมมอง

- **รายการบริการ** — การ์ดแต่ละบริการ คลิกเพื่อกางรายละเอียด (ผู้รับบริการ · ทีม · สิ่งที่ต้องเตรียม · กำหนดการ)
- **ภาพรวม Gantt** — ตารางไทม์ไลน์ 12 เดือนของทุกบริการในหน้าเดียว คลิกที่แถวเพื่อกางรายละเอียดได้เช่นกัน

กรอง/ค้นหาได้ตามคำค้น กลุ่มงาน (STG · PLAN · BUDGET · Research · RISK)
ผู้รับบริการ (บุคลากร · หน่วยงาน · บุคคลภายนอก) และสถานะ

ปุ่ม **ℹ️ คำนิยาม / ชื่อเต็มกลุ่มงาน** กางกล่องอธิบายชื่อเต็มของแต่ละกลุ่มงาน
และนิยามของผู้รับบริการแต่ละประเภท

## สถานะ

| สี | ความหมาย |
|---|---|
| 🟠 | ถึงกำหนด/กำลังดำเนินการ |
| 🟤 | ควรเริ่มเตรียมการ (เดือนหน้า) |
| 🔵 | ยังไม่ถึงกำหนด |
| ⚪ | ผ่านช่วงดำเนินการแล้ว |
| 🟢 | ดำเนินการต่อเนื่องตลอดปี |

สถานะทุกรายการคำนวณอัตโนมัติจาก **วันที่ปัจจุบันจริง** ตอนที่เปิดหน้า
โดยยึดเวลาไทย (Asia/Bangkok) เสมอ ไม่ว่าเครื่องผู้ใช้จะตั้ง timezone ไว้อย่างไร
จึงไม่ต้องแก้ไฟล์เมื่อขึ้นเดือนหรือขึ้นปีใหม่

## ⚠️ สถานะข้อมูล

ช่วงเวลาของหลายรายการยังเป็น **ข้อมูลร่างเบื้องต้น** ยังไม่ได้รับการยืนยันจากเจ้าของภารกิจ
(การ์ดที่เป็นร่างจะมีแถบเตือนกำกับไว้) โปรดตรวจสอบกับเจ้าของภารกิจก่อนนำไปใช้สื่อสารจริง

## โครงสร้าง

ไฟล์เดียวจบ — `index.html` รวม HTML/CSS/JS และข้อมูลทั้งหมดไว้ในไฟล์เดียว
แก้ข้อมูลบริการได้ที่ตัวแปร `ITEMS` ในแท็ก `<script>`
ฟอนต์โหลดจาก Google Fonts (Kanit + Sarabun) จึงต้องต่ออินเทอร์เน็ต

เปิดใช้งานได้โดยเปิด `index.html` ในเบราว์เซอร์โดยตรง ไม่ต้องมี build step
